## 🧠 核心方法论

| 方法论 | 说明 |
|---|---|
| **三单匹配**<br><sub>Three-Way Matching</sub> | 采购订单 / 收货单 / 发票三方核对，定位差异并按类归因 |
| **多源数据对账**<br><sub>Multi-source Reconciliation</sub> | OMS / DMS / SAP 等系统间数据一致性校验，差异可下钻到单据 |
| **可复核输出**<br><sub>Reviewable Output</sub> | 每个结论附带口径说明、源数据逻辑与运行记录，支撑审计留痕 |
